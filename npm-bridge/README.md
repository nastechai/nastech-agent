# nastech-agent npm bridge

An npm bridge for [Nastech Agent](https://github.com/nastechai/nastech-agent) — the self-improving AI agent that creates skills from experience.

## Install

```bash
npm install -g nastech-agent
```

Requires Python 3.11 or newer. The postinstall step installs the `nastech-agent` Python package automatically.

## Usage

```bash
nastech
nastech-agent
```

## Version

This npm bridge tracks PyPI release `nastech-agent==0.18.0`.
